2. Struktura dokumentu

<?xml version="1.0" encoding="utf-8"?>
<metadataAnalysis schemaVersion="1.0" savedAt="2026-11-12T07:32:11.2457699+00:00">
  <Assembly name="SampleLibrary" version="1.0.0.0" culture="neutral"
            fileName="SampleLibrary.dll" location="Memory"
            loadedAt="2026-11-12T08:32:11.2371569+01:00" runtimeVersion="sample">
    <namespaces>
      <namespace name="SampleLibrary.Core">
        <types>
          <type name="UserService" fullName="SampleLibrary.Core.UserService" kind="Class"
                visibility="Public" baseType="object" isStatic="false" ...>
            <genericParameters />
            <interfaces><interface>IUserService</interface></interfaces>
            <fields><field name="_repository" type="IUserRepository" visibility="Private" /></fields>
            <properties><property name="Count" type="int" canRead="true" /></properties>
            <constructors><constructor><parameters>...</parameters></constructor></constructors>
            <methods><method name="GetUser" returnType="User"><parameters>...</parameters></method></methods>
          </type>

Czasy zapisywane są w formacie O (ISO 8601) i zawsze w kulturze niezmiennej — odczyt odtwarza dokładnie ten sam moment w czasie.

4. Zmiany poza Core

  • AddMetadataAnalyzerCore(..., repositoryOptions) — repozytorium XML jest domyślną implementacją; InMemoryMetadataRepository pozostaje w kodzie dla testów i użycia w pamięci.
  • ApplicationOptions.RepositoryPath + appsettings.json (CLI i WPF): "RepositoryPath": "Repository".
  • SettingsService.SaveAsync zachowuje RepositoryPath przy zapisie ustawień.
  • ConstructorModel i MethodModel porównują parametry po sygnaturze — model po odczycie z XML jest równy modelowi sprzed zapisu.
  • UI bez zmian: przyciski zapisu/odczytu w WPF i opcje 6/7 w CLI korzystają z tego samego kontraktu.
