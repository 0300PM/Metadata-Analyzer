2. Spójny model błędów

Każdy błąd wychodzący z warstwy usługowej to MetadataServiceException z kodem, nazwą assembly, ścieżką pliku i zachowanym wyjątkiem wewnętrznym. Anulowanie pozostaje OperationCanceledException.

KodKiedy
SourceNotFoundFileNotFoundException, DirectoryNotFoundException
InvalidAssemblyInvalidDataException i inne błędy providera (uszkodzony obraz)
AccessDeniedUnauthorizedAccessException
RepositoryCorruptedRepositoryDocumentException — uszkodzony/obcy dokument XML
RepositoryUnavailableIOException i pozostałe błędy we/wy repozytorium
InvalidSource / Unknown / CancelledWartości rezerwowe kontraktu

3. Odporność i współbieżność

  • SemaphoreSlim serializuje operacje analizy — równoległe wywołania nie nadpiszą Current w niekontrolowany sposób.
  • CancellationToken jest przekazywany do providera i repozytorium; anulowanie przerywa cały łańcuch i nie zapisuje częściowych danych.
  • Brak repozytorium → czytelny InvalidOperationException przy operacjach repozytoryjnych; analiza działa dalej.
  • Zdarzenia MetadataUpdated / MetadataUnchanged pokazują w logu, czy odświeżenie zmieniło wynik.

4. Dependency Injection

services.AddMetadataAnalyzerCore(
    useMockData, assemblyPath, reflectionOptions, repositoryOptions);

IMetadataProvider     → MetadataProviderResolver → { MockMetadataProvider | ReflectionMetadataProvider }
IMetadataRepository   → XmlMetadataRepository  (InMemoryMetadataRepository podmienialny w testach)
IMetadataService      → MetadataService

Usługa przyjmuje wyłącznie interfejsy — podmiana providera lub repozytorium nie wymaga zmiany logiki ani UI. Test ServiceWorksWithAnyRepositoryImplementation potwierdza to na InMemoryMetadataRepository.

5. Zmiany w CLI (minimalne)

  • Nowa pozycja menu [8] Refresh analysis and save — ponowna analiza ostatniego pliku i aktualizacja wpisu w repozytorium; bez wcześniejszej analizy pliku wyświetla czytelne ostrzeżenie.
  • Pozostałe opcje (5, 6, 7) korzystają z rozszerzonego kontraktu bez zmian w prezentacji.
  • WPF bez zmian — korzysta z tych samych metod usługi.
